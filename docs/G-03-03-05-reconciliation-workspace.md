# G-03-03-05 銀行對帳雙向核對工作區

## 範圍
- 在既有銀行／信用卡對帳工作區顯示帳務端未配對的正式收入與支出。
- 顯示期初／期末餘額的帳務計算值、對帳單值與差異。
- 支援人工分類銀行端與帳務端差異，並要求結案說明。
- 顯示差異處理歷史與雙向對帳最終驗收報告。
- 只有最終報告明確回傳 \`ready_to_complete=true\` 時，前端才啟用完成按鈕；後端在完成交易中重新執行驗證。

## 安全與帳務邊界
- 所有新增檢視均使用既有授權 API，餘額與最終報告要求家庭層級交易資料範圍。
- 帳務獨有清單僅列出有效收入／支出，排除作廢與已配對交易；期初餘額不視為當期未配對收支。
- 分類、說明或結案不會建立、修改、作廢或調整正式交易，也不會修改銀行原始明細。
- 銀行端金額／日期差異必須同時連結銀行明細與正式交易。
- 所有差異處理仍透過既有稽核紀錄。

## 驗收
- Web 測試確認頁面提供期初／期末餘額欄位、帳務獨有清單、餘額核對、差異歷史及最終報告。
- Web 測試確認前端呼叫 ledger-only、balance-check、issues、final-report API。
- API 測試確認 ledger-only 不會列出 opening_balance。
- 手機版在 760px 以下改為單欄排列。
