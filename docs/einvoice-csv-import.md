# 電子發票 M/D 分隔 CSV 匯入預覽

## 目的

支援電子發票匯出檔的 pipe-delimited 格式。第一階段只在使用者瀏覽器解析，提供發票表頭與商品明細預覽及金額核對；不會將原始 CSV 上傳伺服器、不會寫入資料庫，也不會建立正式交易。

## 支援格式

- 表頭列：`M|載具名稱|載具號碼|發票日期|商店統編|商店店名|發票號碼|總金額|發票狀態`
- 明細列：`D|發票號碼|小計|品項名稱`
- 可選擇包含 `表頭=`、`明細=` 前綴的欄位說明列。
- 資料列以 `M|` 或 `D|` 開頭，欄位分隔符號為直線 `|`。
- 支援 UTF-8、Big5（瀏覽器 TextDecoder 的 big5 編碼名稱）與 UTF-8 BOM。
- 日期採西元 `YYYYMMDD`。
- 金額支援整數及最多兩位小數；D 明細可為負數或零。

## 解析與核對規則

1. 依發票號碼將 M 表頭與 D 明細配對。
2. 保留原始明細列，不合併相同商品。
3. 負數明細視為折扣／折讓等調整項，不可刪除或改成正數。
4. 每張發票計算 D 明細加總，與 M 表頭總金額比較。
5. 無明細、明細加總不一致、重複表頭、找不到表頭的明細及格式錯誤均列為待檢查。
6. 載具號碼不顯示在預覽畫面，避免不必要揭露。

## 第一階段限制

- 檔案上限 10 MB；最多 20,000 個非空白／來源行。
- 只辨識本次選取檔案內的重複發票號碼，尚未比對資料庫既有發票或其他匯入批次。
- 預覽資料只存在目前頁面的記憶體中；重新整理或離開頁面後需重新選取檔案。
- 尚未保存匯入批次、附件原檔、載具歸屬或商品分類。
- 尚未建立帳務交易、帳單或付款，也不會自動把發票總額併入家庭支出。
- 尚未實作跨檔案／跨月份重複偵測、資料庫持久化、類別建議及正式確認匯入。

## 人工驗收清單

- [ ] 上傳含 `表頭=`／`明細=` 欄位說明列的原始 CSV。
- [ ] 上傳不含欄位說明列的 CSV。
- [ ] UTF-8 BOM 與 Big5/CP950 中文店名、商品名顯示正常。
- [ ] 同一張發票多筆 D 明細正確歸在同一張 M 發票下。
- [ ] 負數折扣與零元贈品明細均保留。
- [ ] 發票明細加總不一致時顯示差額，不自動調整金額。
- [ ] 缺少表頭的 D 明細與格式錯誤行會列出警示。
- [ ] 載具號碼不會出現在畫面。
- [ ] 手機直向畫面可閱讀發票卡片及展開明細。
- [ ] 確認原始 CSV 不會送到伺服器，也不會產生正式交易。
