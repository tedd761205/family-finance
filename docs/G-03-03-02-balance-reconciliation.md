# G-03-03-02 期初／期末餘額核對

狀態：API 與計算服務已建立，待 CI 驗證。

## 計算原則

- 使用對帳工作階段的帳戶、幣別與台灣本地日期期間。
- 期初帳務餘額 = 有效期初餘額交易 + 對帳期間開始前的有效收支淨額。
- 期末帳務餘額 = 期初帳務餘額 + 對帳期間內的有效收支淨額。
- 一般資產帳戶（銀行、現金、電子支付）：收入增加資產、支出減少資產。
- 信用卡：支出增加欠款、收入／退款減少欠款；正數代表欠款。
- 作廢交易不納入；期初餘額交易作為基準，不重複列入期間收支。
- 對帳單未提供期初或期末餘額時，對應差異回傳 null，不推測數值。
- 差異定義為「帳務計算值 - 對帳單值」。
- 只允許 family 層級交易資料範圍進行完整帳戶餘額核對，避免 own 範圍被誤認為整個帳戶。
- API 為唯讀，不更改交易、對帳單或帳戶餘額，不新增 Migration。

## API

GET /reconciliations/sessions/{session_id}/balance-check?family_id={family_id}

回傳期初／期末帳務值、對帳單值、差異、是否相符及正負數慣例。
