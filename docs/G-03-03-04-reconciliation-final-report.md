# G-03-03-04 完整對帳驗收與結案報告

## 驗收範圍
完成對帳前必須同時確認：
1. 銀行端：每筆銀行明細已完整配對或有有效排除紀錄。
2. 帳務端：期間內未配對正式交易已人工說明並結案；單純未配對不自動判定錯帳。
3. 差異端：所有差異都已結案並留下處理說明。
4. 餘額端：若對帳單提供期初／期末餘額，必須與帳務計算一致；未提供的餘額不推測、不當成差異。

## 結案規則
- 尚有銀行未核對列、未說明帳務獨有交易、未結案差異或期初／期末餘額不符時，拒絕完成。
- 已結案的 ledger_only 差異視為已人工說明，不再阻擋結案。
- 所有檢查在完成操作的資料庫交易中重新執行，避免只依賴前端報告。
- 重新開啟仍沿用既有權限、原因及 audit log 流程。
- 不自動新增、修改、作廢或調整正式交易。

## 結案報告
GET /reconciliations/sessions/{session_id}/final-report?family_id={family_id}

回傳：
- 銀行端總列數、已配對、已排除、未核對。
- 帳務端未配對交易數。
- 差異類別統計、未結案項目及已結案數。
- 期初／期末餘額核對結果。
- ready_to_complete 與 completion_blockers。

報告為唯讀，不更新 session 或任何帳務資料。
